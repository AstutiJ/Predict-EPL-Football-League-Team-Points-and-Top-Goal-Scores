EPL ScoreSight ⚽

AI-Powered Football Analytics & Goal Prediction System

This project predicts English Premier League (EPL) player goal performance and match outcomes using Machine Learning models. It includes data preprocessing, exploratory data analysis, feature engineering, model training, and an interactive prediction application.

📌 Project Overview

Football analytics is becoming increasingly important for teams, analysts, and fans.
This project uses machine learning techniques to analyze EPL player statistics and predict goal-scoring performance based on key match metrics.

The system processes player data, trains predictive models, evaluates performance, and allows users to generate predictions through a simple interface.

📊 Machine Learning Workflow

Data Collection
EPL player performance dataset containing statistics like goals, shots, passes, and appearances.

Data Cleaning
Handling missing values and encoding categorical variables.

Exploratory Data Analysis
Visualization of player statistics and performance trends.

Feature Scaling
StandardScaler and MinMaxScaler used to normalize data.

Model Training
Training multiple ML models for goal prediction.

Model Evaluation
Comparing models using performance metrics.

Deployment
A simple Streamlit web app to generate predictions interactively.
